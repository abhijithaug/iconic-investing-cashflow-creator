Why we built it

Every deal starts with the cashflow.

Iconic Investing helps everyday Australians buy investment property with their eyes open. We built Cashflow Creator so clients can test a deal themselves, using the same inputs we use when we assess a property.

  1. Enter the price, rent and loan for any address.
  2. Check the after-tax weekly cashflow and yield.
  3. Project value, rent and equity out to 30 years.
  4. Save the property and compare it with others.
